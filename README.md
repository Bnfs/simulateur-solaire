# ☀️ Simulateur solaire – Fontaine d'Ouche (Dijon)

Solution collective du **Hackathon #5 2026** (défi RESPONSE / Dijon Métropole) sur l'autoconsommation collective (ACC) dans les logements sociaux de Grand Dijon Habitat et Orvitis.

Le simulateur montre à un locataire ce que les pergolas photovoltaïques de son immeuble lui rapportent (parties communes et adhésion à l'ACC), et explique les démarches pour participer.

**👉 Version en ligne : https://bnfs.github.io/simulateur-solaire/**

## Contenu
- `index.html` : le simulateur en 3 étapes (Bootstrap 5.3, fonctionne hors ligne)
- `vendor/` : Bootstrap 5.3.3 et Bootstrap Icons 1.11.3 (copies locales)
- `logo-dijon-metropole.png`, `logo-response.png` : logos
- `Formulaire_GDH_53_55_OGGA.pdf` : formulaire d'autorisation d'accès aux données (onglet « Démarches »)

## Données
Séries mensuelles issues des suivis GDH et Orvitis (oct. 2025 à sept. 2026), calculettes statiques et livrable RESPONSE D6.12. Résultats indicatifs, non contractuels. Prototype de hackathon.
